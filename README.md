# Pastelaria Mais Sabor — Linktree

Página de link-in-bio e cardápio digital da **Pastelaria Mais Sabor**, feita para usar na bio do Instagram e do WhatsApp. Delivery apenas, com pedidos por WhatsApp, iFood e 99Food.

## 🔗 Demo

- Página principal: https://claude.ai/artifact/GhiKFj97LFDWFTFD4im5Sq
- Cardápio: https://claude.ai/artifact/UhZafTAvZQ3L7BnDxmcDAr

## 📂 Estrutura

```
pastelaria-mais-sabor/
├── index.html       # página principal (linktree)
├── cardapio.html     # cardápio completo
├── css/
│   └── styles.css    # todo o estilo do site
├── js/
│   └── script.js      # reservado para futuras interações
└── img/
    └── logo.png       # logo oficial da pastelaria
```

## 🛠️ Tecnologias

- HTML5
- CSS3 (variáveis CSS, flexbox e grid, sem framework)
- Google Fonts: [Fraunces](https://fonts.google.com/specimen/Fraunces) (títulos) e [Inter](https://fonts.google.com/specimen/Inter) (texto)

Sem JavaScript ativo e sem dependências — só abrir o `index.html` no navegador já funciona.

## ▶️ Como rodar localmente

1. Clone o repositório
2. Abra o arquivo `index.html` no navegador (duplo clique) ou use a extensão **Live Server** do VS Code

Não precisa de build, servidor ou instalação de pacotes.

## 🚀 Deploy

O projeto é 100% estático, então funciona em qualquer serviço de hospedagem de site estático:

- **GitHub Pages**: Settings → Pages → selecionar a branch `main`
- **Netlify** ou **Vercel**: importar o repositório, sem configuração extra

## 🎨 Identidade visual

Paleta baseada na logo oficial: fundo preto quente, dourado (`#e0a53f`) e vermelho da faixa (`#9c2b2b`), texto em creme. Cores centralizadas em variáveis CSS no topo de `styles.css`, fáceis de ajustar.
